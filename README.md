# _2ndy Client (Fabric, Minecraft 1.21.11)

- **Right Shift** — меню модулей
- **Чат (T)** — перетаскивание HUD-элементов мышкой
- **C** — зум (зажать)
- Вкладка **Цвет** в меню — любой цвет интерфейса (R/G/B или готовые)
- У каждого HUD-модуля есть переключатель **Фон** (прозрачный фон)
- У модулей с кнопкой **Настр.** в меню есть своя страница настроек: ползунки, переключатели, выбор режима, цвет (R/G/B, готовые цвета, радуга)
- **Hit Color** лежит в папке `optional-hitcolor/` (см. INSTALL.txt) — подключай после того, как основная сборка прошла
- **Custom Crosshair** (Визуал) — свой прицел: стиль, размер, толщина, зазор, цвет, обводка, цвет на цели
- **Target HUD**, **Attack Cooldown**, **Kill Counter** (PvP), **Death Point** (HUD) — все с настройками
- **Pearl Trajectory** (Визуал) — траектория эндер-жемчуга в руке (2D-оверлей, от первого лица, учитывает только блоки)
- **Hit Sound** (PvP) — звук удара: один из встроенных или **свой файл**. Положи `.wav` / `.ogg` в папку `.minecraft/config/secondy_client/sounds/` (кнопка «Открыть папку со звуками» в настройках модуля), выбери «Источник: Свой файл» и кликни по строке «Файл» — звук сразу проиграется. MP3 не поддерживается: сконвертируй в WAV или OGG. Звук длиннее 5 секунд обрезается.
- **Armor Break Alert** (PvP) — предупреждение, когда прочность брони ниже порога (текст на экране + сигнал)
- **Presets** (Утилиты) — 5 слотов: сохранить / загрузить / очистить все настройки модулей (в подписи слота видно, занят он или пуст). Файлы лежат рядом с конфигом: `secondy_client_preset_N.json`
- **Оптимизация** (вкладка «Оптимиз.») — больше FPS через штатные настройки игры. Каждый пункт включается отдельно: лимит FPS в свёрнутом окне (по умолчанию включён, картинку не трогает), снять лимит FPS, выключить VSync, тени существ, частицы, дальность существ, ограничение прорисовки, сглаживание биомов. Три готовых профиля: безопасный / баланс / максимум. Твои исходные настройки запоминаются и возвращаются при выключении модуля и выходе из игры (бэкап лежит в `config/secondy_client_optimizer_backup.json`, на случай вылета). Пока модуль включён, он держит выбранные значения: если меняешь эти же параметры в настройках игры, сначала выключи соответствующий пункт.
- **Высокая трава** убирается не модулем, а ресурспаком `_2ndy_no_grass_pack.zip` (положить в `resourcepacks/` и включить в меню ресурспаков).
- Новые модули: Day Counter, Playtime, Health, XP Display, Held Item, Dimension, Fall Distance, Pot Counter, Pearl Counter, Arrow Counter (по умолчанию выключены)

Сборка: вкладка **Actions** на GitHub → последний запуск `build` → **Artifacts** → `secondy-client-jar`.
Локально: `gradle build` (Gradle 9.2.1, Java 21), jar будет в `build/libs/`.
